# BURGER HOUSE — Luxury Multi-Branch Restaurant Ordering & KDS Platform

منظومة **BURGER HOUSE (برجر هاوس)** هي منصة طلبات مطاعم تجارية فاخرة ومستقلة بالكامل مبنية من الصفر باستخدام **Next.js 14 (App Router)** و **TypeScript** و **Tailwind CSS** و **Supabase (PostgreSQL + Auth + RLS + Storage + Realtime)**.

---

## 1. المعمارية والواجهات الأربع المستقلة

| البوابة / المسار | الفئة المستهدفة | الوظائف الرئيسية |
| :--- | :--- | :--- |
| **`/` (واجهة العميل الفاخرة)** | زوار وعملاء المطعم | منيو تفاعلي، تخصيص الأحجام والإضافات، تحديد أقرب فرع مفتوح عبر GPS (مع استبعاد الفروع المغلقة تلقائياً)، خريطة الفرع التفاعلية، واختيار الاستلام من الفرع. يتطلب إنشاء الطلب حساب عميل موثقًا بالبريد الإلكتروني ورقم جوال سعودي محفوظ في الملف الشخصي.
| **`/staff/orders` (شاشة الموظفين KDS/POS)** | مدير الفرع، الكاشير، موظف المطبخ | استقبال الطلبات الفوري بالصوت، عزل صارم لكل فرع، 8 حالات منطقية للطلب، تأكيد قبل الرفض/الإلغاء، توثيق اسم الموظف والوقت، وطباعة إيصال حراري 80mm وفاتورة ضريبية. |
| **`/owner-studio` (لوحة مالك المطعم)** | مالك المطعم (`owner`) | إحصائيات حقيقية وتقارير مبيعات الفروع، إدارة الفروع وساعات العمل، إدارة المنيو واختلاف الأسعار بين الفروع، رفع صور المنتجات من الهاتف، تفعيل/إخفاء وسائل الدفع، إدارة الموظفين، وتخصيص الهوية مع المعاينة قبل النشر. |
| **`/bh-sovereign-vault` (لوحة الإدارة العليا)** | منشئ النظام فقط (`super_admin`) | مسار خفي ومستقل محمي على الخادم (يُمنع مالك المطعم `owner` من دخوله بـ `403 Forbidden`)، إيقاف/تشغيل الموقع بالكامل، وضع الصيانة، إدارة حساب المالك، جدار الحماية وحظر الأرقام/IPs، والنسخ الاحتياطي الكامل. |

## 2. حساب العميل والمصادقة

- إنشاء الحساب: الاسم + البريد الإلكتروني + كلمة المرور + رقم جوال سعودي إلزامي.
- التحقق من ملكية البريد عبر رمز OTP من 6 أرقام.
- تسجيل الدخول اليومي: البريد الإلكتروني وكلمة المرور؛ لا يوجد تسجيل دخول برقم الجوال.
- رقم الجوال محفوظ بصيغة `9665XXXXXXXX` ويُستخدم لربط الطلبات وتحديثات الاستلام. لا يتطلب SMS OTP.

## 3. التشغيل السريع والاختبارات الآلية

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل حزمة الاختبارات الآلية الشاملة (9 مجموعات اختبار للوظائف الحساسة)
npm test

# 3. تشغيل بيئة التطوير المحلية
npm run dev
```

> **ملاحظة للمعاينة الفورية بدون خادم:** يتضمن المشروع أيضاً نسخة تفاعلية مستقلة بالكامل داخل `public/live-demo/index.html` تعمل مباشرة في المتصفح وتضم جميع البوابات الأربع.
