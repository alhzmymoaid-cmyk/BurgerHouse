# إعداد التحقق بالبريد الإلكتروني (OTP)

تم تجهيز واجهة التسجيل والتحقق في التطبيق لتستخدم رمز Supabase OTP من 6 أرقام عبر `verifyOtp({ type: 'signup' })`.

## إعداد Supabase المطلوب مرة واحدة

افتح [Auth > Email Templates](https://supabase.com/dashboard/project/kgmteyikhadzqbscnlfb/auth/templates) في مشروع Burger House:

1. افتح قالب **Confirm signup**.
2. اجعل العنوان: `رمز التحقق لحسابك في BURGER HOUSE`.
3. استبدل محتوى القالب بمحتوى الملف `supabase/templates/customer-confirmation-otp.html`.
4. تأكد أن القالب يحتوي `{{ .Token }}` ويعرض الرمز، ولا يعتمد على `{{ .ConfirmationURL }}`.
5. من **Auth > Providers > Email** فعّل Email provider وفعّل Confirm email.
6. قبل الإطلاق العام، اربط SMTP مخصصًا موثوقًا من إعدادات SMTP في Supabase، واختبر وصول الرسائل وإعادة إرسال الرمز.

## سلوك التطبيق

- إنشاء حساب بالبريد وكلمة مرور.
- إرسال رمز تأكيد من 6 أرقام عبر قالب تأكيد التسجيل.
- التحقق باستخدام نوع `signup`.
- إعادة إرسال الرمز باستخدام `resend({ type: 'signup' })`.
- تسجيل الدخول بالبريد وكلمة المرور.
- لا يسمح API بإنشاء طلب ما لم يكن البريد مؤكدًا.
- التسجيل يعتمد على البريد الإلكتروني وكلمة المرور، ثم رمز OTP من 6 أرقام عبر البريد.
- رقم الجوال السعودي مطلوب عند إنشاء الحساب، ويُحفظ بصيغة `9665XXXXXXXX` في بيانات العميل تلقائيًا عبر Database Trigger.
- تسجيل الدخول اليومي بالبريد وكلمة المرور فقط؛ لا يُرسل SMS OTP ولا يُطلب رقم الجوال كمعرّف دخول.
- رقم الجوال نفسه يُستخدم عند إتمام الطلب، ويتحقق الخادم من مطابقته لرقم الحساب؛ لا يلزم SMS OTP.

> ملاحظة: ملفات SQL لا تغيّر إعدادات قوالب البريد في مشروع Supabase المستضاف. يجب تطبيق قالب البريد وإعداد SMTP من لوحة Supabase نفسها.

## تجهيز آلي لإعداد المشروع المستضاف

أُضيف سكربت `scripts/configure-supabase-auth.mjs` ليضبط قالب Confirm signup وSMTP عبر Supabase Management API دفعة واحدة، دون تخزين الأسرار في المستودع.

المتغيرات المطلوبة وقت التشغيل فقط:

- `SUPABASE_ACCESS_TOKEN`: رمز وصول شخصي من Supabase Dashboard > Account > Access Tokens.
- `SUPABASE_PROJECT_REF`: مرجع مشروع Burger House.
- `SMTP_ADMIN_EMAIL`: عنوان المرسل المعتمد لدى مزود البريد.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`: بيانات SMTP من المزود.

بعد تجهيز هذه المتغيرات في بيئة آمنة، شغّل:

```bash
node scripts/configure-supabase-auth.mjs
```

يتحقق السكربت من وجود رمز OTP في القالب، ويُبقي تأكيد البريد إلزاميًا، ويُفعّل SMTP الخارجي. لا يطبع أي قيمة سرية. لا تضع بيانات الاعتماد في Git أو ملفات المشروع.

**المتبقي الخارجي الوحيد:** إنشاء/اعتماد حساب مزود إرسال بريد والتحقق من نطاق المرسل، ثم توفير بيانات SMTP ورمز Supabase Management API لتشغيل السكربت. لا يمكن تفعيل الإرسال العام باستخدام خدمة Supabase الافتراضية؛ فهي مخصصة للاختبار وعناوين أعضاء الفريق فقط.
